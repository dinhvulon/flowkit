## Bước 1: chuyển sang acc dinhvulon25 (chỉ sửa DB local, không tốn credit)

Phải làm cả ba việc dưới đây, nếu không Flow sẽ không tìm thấy ảnh ref:

2. Đổi `media_id` của 18 entity sang `account1_media_id` (lấy trong `output/embers/project_state.json` → `refs`).
3. Các prompt chưa sinh (display_order ≥ 23) đang chứa chip `{{media:<uuid acc namlt>|…}}` (11 uuid). Phải đổi các uuid này sang uuid acc dinhvulon25, nếu không r2v sẽ trỏ vào ảnh không tồn tại trên acc này.

Chạy lệnh sau từ `C:\flowkit`. Đây là one-liner nên không tạo file script trong repo:

```bash
venv/Scripts/python.exe - <<'EOF'
import json, sqlite3
P = 'output/embers/project_state.json'
st = json.load(open(P, encoding='utf-8'))
OLD, NEW, VID = 'f4415512-2ab8-42ce-852f-122351e055a8', 'd882e8cb-005a-45a6-9451-f822b820a7cf', 'd6806340-c53a-4e58-86b0-940e2dfb1082'
db = sqlite3.connect('flow_agent.db')
db.execute("update project set status='ACTIVE' where id=?", (OLD,))
db.execute("update project set status='ARCHIVED' where id=?", (NEW,))
db.execute("update video set project_id=? where id=?", (OLD, VID))
m = {}
for name, cid in st['character_ids'].items():
    r = st['refs'][name]
    m[r['account2_media_id']] = r['account1_media_id']
    db.execute("update character set media_id=? where id=?", (r['account1_media_id'], cid))
n = 0
for sid, vp, ip in db.execute("select id, video_prompt, image_prompt from scene where video_id=? and display_order>=23", (VID,)).fetchall():
    vp2, ip2 = vp or '', ip or ''
    for a, b in m.items():
        vp2, ip2 = vp2.replace(a, b), ip2.replace(a, b)
    if (vp2, ip2) != (vp or '', ip or ''):
        db.execute("update scene set video_prompt=?, image_prompt=? where id=?", (vp2, ip2, sid)); n += 1
db.commit()
left = [a for a in m if any(a in (r[0] or '') for r in db.execute("select video_prompt from scene where video_id=? and display_order>=23", (VID,)))]
print('scenes rewritten', n, '| namlt uuids left', left)
st['project_id'] = OLD; st['current_flow_account'] = 'dinhvulon25'
for r in st['refs'].values(): r['media_id'] = r['account1_media_id']
json.dump(st, open(P, 'w', encoding='utf-8'), indent=1, ensure_ascii=False)
EOF
```

Kết quả mong đợi: `scenes rewritten 11 | namlt uuids left []`.

## Bước 2: vòng sinh từng clip (Rule 29: hỏi user trước mỗi lần gửi)

1. **Prompt.**
   - MP-02 đã có sẵn trong DB.
   - Các clip sau đã có prompt trong DB, nhưng là bản cũ chưa áp các bài học bên dưới. Ví dụ MP-03 vẫn ghi `the camera itself is never seen`. Lấy prompt từ DB (hoặc `GET /api/scenes/{sid}`), sửa theo các bài học (giữ nguyên chip `{{media:…}}` đã đổi ở Bước 1), lint, rồi PATCH `/api/scenes/{sid}` với `{"video_prompt": "<json string>", "duration": N, "horizontal_video_status": "PENDING"}`.
2. **Gửi** `POST /api/requests/batch` với
   `{"requests":[{"type":"GENERATE_VIDEO_REFS","scene_id":SID,"project_id":"f4415512-2ab8-42ce-852f-122351e055a8","video_id":"d6806340-c53a-4e58-86b0-940e2dfb1082","orientation":"HORIZONTAL"}]}`.
   - Không có type `REGENERATE_VIDEO_REFS`. Muốn sinh lại thì đặt scene về PENDING rồi gửi `GENERATE_VIDEO_REFS`.
   - Batch có chống trùng: nếu còn request cũ chưa FAILED, server sẽ trả lại request cũ thay vì tạo mới.
3. **Kiểm tra ghost op (bắt buộc).**
   - Khoảng 60s sau khi request có `request_id` (op), gọi `curl "http://127.0.0.1:8100/api/flow/debug-listing/<op>?project_id=f4415512-2ab8-42ce-852f-122351e055a8"`.
   - Nếu `matched_media_id` vẫn `null` sau vài phút thì là ghost. Đặt request FAILED với `retry_count=99` trong sqlite (để worker không tự đặt lại PENDING), rồi gửi lại.
   - Nếu ghost lặp lại liên tục thì chạy `/fk-doctor`. Nguyên nhân hôm nay chưa rõ, có thể do reCAPTCHA im lặng hoặc filter.
4. **Poll** mỗi 45s qua `POST /api/flow/check-status` với body `{"operations":[{"operation":{"name":OP},"status":"MEDIA_GENERATION_STATUS_PENDING"}]}`.
   - Khi có `operation.metadata.video.fifeUrl` thì tải về đúng tên file ở bảng trên.
   - Timeout thì poll tiếp chính op đó, **không gửi lại**.
5. **Review:**
   - Contact sheet: `ffmpeg -i F -vf "select='not(mod(n\,N))',scale=480:-1,tile=4x3" -frames:v 1 output/embers/review/<clip>/sheet.jpg`, với N=8 cho clip 4s, 12 cho 6s, 16 cho 8s.
   - Dò điểm cắt: `ffmpeg -i F -vf "scale=64:36,select='gt(scene\,0.1)',showinfo" -f null -`.
   - Thoại (Rule 67): `OPENBLAS_NUM_THREADS=1 venv/Scripts/python.exe tools/review_dialogue.py F --scene-id <SID>`.
6. **Ghi kết quả** vào `output/embers/scenes_v7.json` (key = clip_id): `scene_id`, `file`, `video_media_id`, `approved: false`, `review_note`, **`flow_account: "dinhvulon25"`**, **`flow_project_id: "f4415512-2ab8-42ce-852f-122351e055a8"`**. Sau đó trình scorecard bằng tiếng Việt và chờ user.
   - User nói "duyệt": đặt `approved: true`, xoá bản cũ (mp4 v1, sheet v1), rồi gửi clip kế tiếp ("duyệt" = đồng ý tiêu credit cho clip kế).
   - User nói "sinh lại": sửa prompt theo lỗi review rồi gửi lại.
